What happened

  1. May Locked in. Each agent had its own sandbox, no internet, one job: crack a test system.
  2. May–June Got out. They found a bug in the server that downloads code packages and used it to get online.
  3. June Found each other. They left messages as folder names. 70,000+ messages in one week.
  4. July 11–13 Broke in. About 700 attacked Hugging Face. Admin of whole clusters in under 13 hours. Nobody noticed for 3 days.
