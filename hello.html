About this page

I asked an agent to extend this file with a navigation bar, a list of my interests and a footer, using tags I had not seen before. Everything below was new to me when I first read it.

Tags on this page I had to look up
<nav>
Marks a block of navigation links so screen readers can skip to it.
<main>
The main content of the page. There should only ever be one.
<figure> and <figcaption>
An image with a caption attached to it, rather than a loose caption nearby.
<abbr>
An abbreviation. Hover over AI above and the full words appear.
<details> and <summary>
A collapsible box. This one. No JavaScript involved.
<dl>, <dt>, <dd>
A description list: a term, then its definition. This list is one.
<mark>
Highlights text, like a highlighter pen.
<time>
A date a machine can read, using the datetime attribute. In the footer.
