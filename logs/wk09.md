## Something new I picked up

- await only works inside an async function, and the code after it does not
  run until the fetch is back. Without await you get a Promise, not the data.
- response.ok is a separate check from the catch. A 404 is still a response, so
  try/catch alone lets it through.
- Keys never go in the page. Anything in index.html or js/ is public the moment
  it is deployed.
