## Something I noticed about working with AI

- Making the agent start every answer with my name. When it stops, the chat has got
  too long and it is time for a new one. Cheap test, I would not have thought of it.
- The interview flipped where the work is. The questions I could not answer were
  decisions I had not made, not something the tool was missing.

## CSS so far

- What I learned: a rule is a selector plus properties. Class beats tag, later
  beats earlier when they tie. nav a means links inside the nav. Flexbox for one
  direction, Grid for two. The viewport meta tag plus an @media block is what makes
  a page responsive.
- What I found interesting: the underline on Babson.edu links is a border-bottom,
  not text-decoration. My stylesheet does the same thing now.
- What I do not know yet: my stylesheet has :root variables and a dark mode block
  the agent wrote. I can use them but I could not explain them out loud yet. Also
  I have not used Grid on anything real.
