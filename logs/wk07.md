## Something new I picked up

- The order of the conditions matters. The most specific case has to be checked
  first or the general one catches it.
- return is what hands the number back to the page. A function that only
  console.logs it looks right in the console and does nothing on screen.
- Every message to an agent resends the whole chat, so a long chat costs more
  each time. Starting a new chat per task and pasting text instead of
  screenshots makes the $100 last.

## Something I noticed about working with AI

- Writing getDiscount myself first and then asking the agent to check it was the
  right order. It found nothing wrong, which told me more than if it had written
  the function for me.
- The course site has an MCP server now, so the agent can look up deadlines and
  session notes directly instead of me pasting them in.
