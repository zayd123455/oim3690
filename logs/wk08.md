## Something new I picked up

- for...of goes through an array item by item with no counter. The loop variable
  is the singular of the array: for (const song of songs).
- In getVerdict, each if ends with return, so there is no else. The first check
  that matches wins, which is why the order of the checks matters.
- Fixing one thing can move line numbers. My fix added 7 lines, so every line
  number after it in my notes was off by 7.
