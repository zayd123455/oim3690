## Something new I picked up

- What cascading actually means. More specific selector wins (id beats class beats
  tag), and if they tie the later one wins. Inline beats all of that.
- The file has to be css/styles.css letter for letter. Same lesson as Logs vs logs
  from week 2, a wrong name looks fine on my Mac and is missing on the server.

## Something I noticed about working with AI

- The agent redesigned my personal site and the first version was way too much: a
