## Something new I picked up

- Folder names are case sensitive on GitHub Pages. Logs and logs are two different
  folders on the server, even though my Mac treats them as the same. A wrong capital
  letter looks fine locally and still counts as missing online.
- Adding a file to .gitignore after you have already committed it does nothing. The
  file stays in the repository and anyone can read it in a public repo. .gitignore
  only applies to files git is not tracking yet.

## Something I noticed about working with AI

- Reading the generated code taught me more than writing it would have. I asked for
  tags I had not seen, and it used <details> and <summary> to build a collapsible
  box with no JavaScript at all. I assumed anything that expands and collapses needed
  a script. It does not, that behaviour is built into HTML.
